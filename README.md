# Cyber Security Workshop — 15-Day Session

This repository contains the syllabus and core modules for a 15-day hands-on Cyber Security Workshop.

## Workshop Overview

- **Duration:** 15 Days  
- **Level:** Beginner to Intermediate  
- **Mode:** Practical / Hands-on Training  
- **Focus Areas:** Cyber Security, Networking, Security Tools, Windows, Linux, and Web Security  

## Core Modules & Topics

### 1. Introduction to Cyber Security  
**Days 1–3**

- What is Cyber Security?
- Importance and Need for Cyber Security
- Types of Cyber Threats
- Types of Cyber Attackers
- Cyber Security Career Domains
- Networking Fundamentals
- Network Types & Devices
- IP Addressing
- Protocols & Ports
- OSI Model & TCP/IP Stack

### 2. Network Security Tools & Techniques  
**Days 4–6**

- Network Scanning Concepts
- Nmap Fundamentals
- Wireshark Fundamentals
- IDS / IPS Concepts
- Basic Vulnerability Assessment

### 3. Information Security Fundamentals  
**Days 7–9**

- CIA Triad
- Confidentiality, Integrity & Availability
- Assets, Threats, Vulnerabilities & Risks
- Security Controls
- Authentication & Authorization

### 4. Windows & Linux Operating Systems  
**Days 10–13**

- Windows OS Fundamentals
- Linux OS Fundamentals
- VirtualBox Installation & VM Creation
- Windows/Linux Installation Basics
- Users, Groups & File Permissions
- Updates, Services & Basic OS Security

### 5. Web & Application Security  
**Days 14–15**

- HTTP vs HTTPS: Secure Web Communication
- OWASP Top 10 Common Web Security Risks
- Web Vulnerabilities:
  - SQL Injection
  - Cross-Site Scripting (XSS)
  - Cross-Site Request Forgery (CSRF)

## Learning Outcomes

After completing this workshop, participants will be able to:

- Understand cybersecurity fundamentals, threats, and attacker types.
- Explain networking basics, IP addressing, protocols, ports, and OSI/TCP-IP models.
- Use basic network security tools such as Nmap and Wireshark.
- Understand IDS/IPS and basic vulnerability assessment.
- Apply CIA Triad, security controls, authentication, and authorization.
- Install and secure Windows and Linux systems using VirtualBox.
- Identify common web application vulnerabilities and secure web communication concepts.

## Tools Covered

- VirtualBox  
- Windows OS  
- Linux OS  
- Nmap  
- Wireshark  
- Web security testing concepts  

## Disclaimer

This workshop is for educational and ethical learning purposes only. Participants must practice only on authorized systems, labs, or virtual environments.
